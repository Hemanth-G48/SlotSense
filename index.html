How the engine works

A reproducible pipeline: data → constraints → optimisation → independent verification. Nothing in the dashboard is hardcoded.

01 · DATA

Warehouse + demand

3×3 rack topology, SKU master data, order lines, ABC velocity and basket affinity from the generated benchmark.

02 · CONSTRAINTS

Hard rules first

3-D fit, volume, per-bin/shelf/rack weight, heavy-SKU height limits, hazard and category separation.

03 · OPTIMISE

Demand-aware placement

Simulated-annealing search over relocation proposals, scoring travel, affinity, ergonomics and utilisation.

04 · PROVE

Independent evaluation

Separate validator re-checks every assignment; baseline and optimized run through the same route simulation.
